## Review Focus

1. **The production bundle targets newer browsers** — Vite 7's default `build.target` is `baseline-widely-available` (Chrome/Edge 107, Firefox 104, Safari 16) where Vite 5 used `es2020, edge88, firefox78, chrome87, safari14`; a DJ on Safari 15 would get a blank page. Pinned in Task 2, checked by grepping the built JS for syntax newer than ES2020 is impractical — the pin itself is asserted by `test_build_target_is_pinned` (Task 2).
2. **Vitest 4 changed mock semantics** (`vi.restoreAllMocks` restores only `vi.spyOn` spies; `vi.fn().mockReset()` restores the original implementation) — tests that relied on the old behavior pass for the wrong reason or fail; every failure is fixed in the test with the migration-guide reason in a comment, never by weakening the assertion.
3. **Browser-mode screenshots lose their fixed locale/timezone** when `providerOptions.context` silently stops applying under the new provider → README images drift by machine. Task 1 moves it to `playwright({ contextOptions })` and checks the option name in the installed types.
4. **`pnpm dev` proxy or `__APP_VERSION__` define breaks** under Vite 7 (config API changes). Task 2 runs `vite build` and checks `__APP_VERSION__` lands in the bundle.
5. **A transitive "fix" downgrades or breaks a runtime package** — `pnpm update --depth Infinity` on names that also exist in the runtime tree. Task 3 re-runs `pnpm audit --prod` and the full test suite after the update.
